MK-71 Keyboard

বাংলা + English অন-স্ক্রিন কিবোর্ড, ভয়েস টাইপিং আর AI

সংস্করণ 1.0.8  ·  Windows 7 / 8.1 / 10 / 11  ·  ৩২ ও ৬৪-বিট
এই নির্দেশিকাটি দুটি ফাইলের সাথে দেওয়া হয়েছে: ৬৪-বিট পোর্টেবল Windows_x64_Portable.zip ও ইনস্টলার Windows_x64_Installer.zip
কে এই গাইডটি পড়বে প্রথমবার MK-71 চালানো যে কেউ। প্রতিটি ফিচার কোথায় আছে, কীভাবে চালু করবেন আর কীভাবে ব্যবহার করবেন — সব ধাপে ধাপে লেখা আছে। কোনো কোডিং জ্ঞান লাগবে না।
যা যা পারবেন ফোনেটিক বাংলা টাইপ, অন-স্ক্রিন কিবোর্ড, যেকোনো অ্যাপে বাংলা লেখা, মাইকে বলে ভয়েস টাইপিং, অটো সাজেশন, এনকোডিং কনভার্টার এবং ঐচ্ছিক AI প্রুফরিডিং — সব একই অ্যাপে।
কী লাগবে উইন্ডোজ ৭ এসপি১ বা তার নতুন সংস্করণ, প্রায় ২৫০ MB ফাঁকা জায়গা। টাইপিং, কনভার্টার ও লোকাল প্রুফরিডিং ইন্টারনেট ছাড়াই চলে; ভয়েস আর AI-এর জন্য ইন্টারনেট দরকার।

এক নজরে MK-71

একটি ছোট অ্যাপে বাংলা ও ইংরেজি লেখার পুরো ব্যবস্থা

MK-71 Keyboard হলো উইন্ডোজের জন্য একটি ফ্রি অন-স্ক্রিন ও ফোনেটিক কিবোর্ড। এটি আপনার কম্পিউটারে সবসময় হালকা একটি টপ বার হিসেবে থাকে; সেখান থেকেই কিবোর্ড, ভয়েস টাইপিং, সেটিংস আর AI — সব চালু করা যায়।

অন-স্ক্রিন কিবোর্ড মাউস বা টাচ দিয়ে বাংলা, ইংরেজি, চিহ্ন ও ইমোজি টাইপ। চারটি ট্যাব, Shift/Space/Enter/Backspace এবং ক্যারেক্টার গ্রিডের জুম।
ফোনেটিক বাংলা ইংরেজি অক্ষরে লিখুন — amar লিখলে আমার হবে। Avro-ধাঁচের ফোনেটিক অথবা ফিক্সড (জাতীয়) লেআউট বেছে নিতে পারবেন।
যেকোনো অ্যাপে বাংলা Chrome, Word, Notepad, WhatsApp — যেখানে কার্সর আছে সেখানেই বাংলা লেখা বসে। আলাদা করে কিছু কপি-পেস্ট করতে হয় না।
ভয়েস টাইপিং মাইকে বলুন, থামুন — লেখা বসে যাবে। ফ্রি Google Web Speech ছাড়াও Google Cloud, Groq Whisper, Deepgram ও Sarvam AI।
সাজেশন ও অটো-কারেকশন পরের শব্দ, তারিখ, সময়, বাংলা সংখ্যা, ইমোজি, ক্যালকুলেটর ফল — টাইপ করার সময়েই ছোট চিপ হিসেবে দেখায়।
এনকোডিং কনভার্টার পুরোনো ANSI/Bijoy, Probhat বা Banglish লেখা এক ক্লিকে ইউনিকোডে রূপান্তর, আবার উল্টোটাও।
AI প্রুফরিডিং (ঐচ্ছিক) বানান ও যতিচিহ্ন ঠিক, সমার্থক ও বিপরীত শব্দ, বাংলায় অনুবাদ। key না দিলেও লোকাল প্রুফরিড চলবে।
অফলাইন ও প্রাইভেট কোনো টেলিমেট্রি নেই, অ্যাকাউন্ট নেই। টাইপ করা অক্ষর আপনার কম্পিউটারেই বাংলায় রূপান্তরিত হয়।

ইনস্টল ও প্রথম চালু

পোর্টেবল সংস্করণ, ইনস্টলার এবং প্রথমবারের সেটআপ

পোর্টেবল সংস্করণ (ইনস্টল ছাড়া)

  1. জিপ ফাইলটি ডান-ক্লিক → Extract All দিয়ে খুলুন। জিপের ভেতর থেকেই সরাসরি চালাবেন না — আগে আনজিপ করুন।
  2. ফোল্ডারটির ভেতরে MK-71 Keyboard.exe আছে। সেটিতে ডাবল-ক্লিক করুন।
  3. প্রথমবার Windows SmartScreen সতর্কতা দিলে More info → Run anyway চাপুন। অ্যাপটি unsigned ও ফ্রি, তাই উইন্ডোজ চিনতে চায়।
  4. টপ বার পর্দার উপরে-মাঝখানে চলে আসবে এবং ট্রেতে আইকন দেখা যাবে।
পোর্টেবল মানে কী? আপনার সব সেটিংস, শব্দভাণ্ডার ও API key data ফোল্ডারে জমা হয় — ঠিক অ্যাপের পাশেই। ফোল্ডারটি USB-তে করে অন্য পিসিতে নিলে সবকিছু সাথে যাবে। ফোল্ডারটি মুছলে সেটিংসও মুছে যাবে, তাই মাঝে মাঝে ব্যাকআপ রাখুন।

ইনস্টলার দিয়ে

  1. Windows_x64_Installer.zip আনজিপ করুন → MK-71 Keyboard Setup.exe চালান।
  2. কোথায় ইনস্টল হবে বেছে নিন (ডিফল্ট ঠিক আছে) → Install।
  3. শেষ হলে Start Menu/ডেস্কটপ শর্টকাট পাবেন। ইনস্টলের পর সেটিংস থাকে %APPDATA%\MK-71 Keyboard (পোর্টেবল ফ্ল্যাগ না থাকলে)।

API key কোথায় বসাবেন নতুন

  1. Settings → Speech to Text → Recognition service → Service থেকে সার্ভিস বাছুন।
  2. নিচে সেই সার্ভিসের API key বক্সে key পেস্ট করুন।
  3. Apply → OK। key সাথে সাথেই কার্যকর।
  4. কোন key কোথা থেকে আনবেন তা ধাপে ধাপে দেখতে How to set API key বাটনে ক্লিক করুন। ডায়ালগে প্রতিটি সার্ভিসের সেকশন আছে, ক্লিকেবল সাইট লিংকসহ; আপনি যে সার্ভিস সিলেক্ট করেছেন সেখানে এটি নিজেই স্ক্রল হয়ে যায়।
কোটা শেষ হলে কী হয়? অ্যাপ নিজেই ফ্রি Google Web Speech-এ নেমে আসে, ফলে লেখা পাওয়া বন্ধ হয় না। Groq-এর কোটা পরদিন ০০:০১-এ, Google Cloud-এর কোটা পরের মাসের ১ তারিখে ফিরে এলে অ্যাপ নিজে থেকেই আবার উন্নত সার্ভিসে ফিরে যায়। Deepgram/Sarvam-এর এককালীন ক্রেডিট শেষ হলে প্রতিদিন একবার আবার চেষ্টা করা হয়। Settings → Speech to Text-এ উপরে কবে ফিরবে তা লেখা থাকে। আবার app বন্ধ-চালু করলেও এই হিসাব ঠিক থাকে।

মাইক ও রিকগনিশন ভাষা

  • টপ বারের মাইকে ডান-ক্লিক → Microphone থেকে ইনপুট যন্ত্র বাছুন; System default রাখলে উইন্ডোজ সিদ্ধান্ত নেবে।
  • Test microphone… ডায়ালগে মিটার নড়লে মাইক ঠিক আছে। সমতল মিটার মানে মাইক mute, ব্লকড বা খোলা হয়নি।
  • Recognition language: বাংলা (বাংলাদেশ) / বাংলা (ভারত), অথবা English (US/UK/Australia/India)।
  • Settings-এ Speech Map বাটন দিয়ে আপনার উচ্চারণে বারবার ভুল শোনা শব্দ ঠিক করে দিতে পারেন।
  • Synchronize Recognized Speech চালু থাকলে ভয়েস শেষ হওয়ার আগে অন্য অ্যাপে ক্লিক করলেও লেখা সেই উইন্ডোতেই বসে।
  • Adjust for ambient noise চালু থাকলে ফ্যান/রাস্তার শব্দকে কথা ভাবা হয় না।
ইন্টারনেট দরকার: ভয়েস টাইপিং সবসময় অনলাইন সার্ভিসে চলে। ইন্টারনেট না থাকলে বাকি সব (টাইপিং, কনভার্টার, লোকাল প্রুফরিড) চলবে, শুধু ভয়েস বন্ধ থাকবে।

যে রূপান্তরগুলো আছে

  • ANSI / Bijoy → Unicode — পুরোনো বিজয় লেখা আধুনিক বাংলায়।
  • Probhat → Unicode — প্রভাত কী-বোর্ডের লেখা।
  • Unicode → ANSI / Bijoy — উল্টো পথ, পুরোনো সফটওয়্যারে দেওয়ার জন্য।
  • Banglish ও Calligraphy/Bold স্টাইল ম্যাপ।

ধাপে ধাপে

  1. Paste চেপে ক্লিপবোর্ডের লেখা উপরের বক্সে আনুন, অথবা সরাসরি লিখুন/টাইপ করুন।
  2. Map থেকে সঠিক রূপান্তর বাছুন।
  3. Convert চাপুন। ফল নিচের বক্সে আসবে।
  4. Copy converted দিয়ে ফল কপি করে যেখানে দরকার পেস্ট করুন।
  5. ভুল হলে Swap দিয়ে দিক উল্টে দেখুন, অথবা Clear দিয়ে নতুন করে শুরু করুন।
ফন্ট: উপরের বা নিচের বক্সে ডান-ক্লিক করে ফন্ট পরিবার ও আকার বদলাতে পারবেন। Ctrl++ / Ctrl+− দিয়েও আকার বদলায়। কনভার্টার সম্পূর্ণ অফলাইনে চলে।
